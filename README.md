# Sourdough Tracker PWA

A Progressive Web App for tracking sourdough baking progress. Add or subtract grams with timestamps, view cumulative totals, and clear history.

## Features
- Add/subtract grams with CET timestamps (DD/MM/YYYY HH:MM)
- Cumulative total tracking
- Local storage for persistence
- Offline support via service worker
- Mobile-optimized responsive design
- PWA installable on devices

## How to Run Locally
1. Install Node.js (if not already).
2. Run `npx http-server .` in the project folder.
3. Open `http://localhost:8080` in your browser.

## Hosting
- Free on GitHub Pages: Push to a GitHub repo and enable Pages in Settings.
- Or use Netlify/Vercel for drag-and-drop deployment.

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- Service Worker for PWA
